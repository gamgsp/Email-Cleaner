================================================================================
       EMAIL CLEANING & AUTO-UNSUBSCRIBER SUITE FOR MACOS (APPLE MAIL & IMAP)
================================================================================

This suite contains two desktop web applications for macOS:

  1. MailSweep  (Email Cleaner — Apple Mail & IMAP Edition)
     Scans mailboxes, groups messages by domain into 9 intelligent
     categories, and safely deletes unwanted promotional, ad, or spam emails.
     Default Port: http://localhost:7890

  2. UnsubBot   (Automated Email Unsubscriber — Apple Mail & IMAP Edition)
     Scans emails for RFC 8058 One-Click headers, RFC 2369 links, and web
     unsubscribe forms, then executes unsubscription with live terminal logging.
     Default Port: http://localhost:7891

================================================================================

2. WHY YOU MIGHT STILL RECEIVE EMAILS & HOW UNSUBBOT SOLVES IT
================================================================================

1. Marketing Delay: Most legitimate newsletters take 24–48 hours to update their
   distribution lists across all global marketing servers.
2. Multiple Subscriptions / Subdomains: A company (e.g. retailers, banks) often
   sends from multiple subdomains (promos.company.com, news.company.com). UnsubBot
   detects each separate subdomain.
3. Verification in Terminal: Check the terminal output when running UnsubBot.
   If a row shows "⚠️ Manual Required" (CAPTCHA or Login required), click
   "[Open Link ↗]" in the UI to complete the final confirmation step.

================================================================================
3. PREREQUISITES & INSTALLATION
================================================================================

1. macOS with Apple Mail open and signed into your account (or use Universal IMAP).
2. Python 3: installed by default on macOS (run `python3 --version` in Terminal).
3. Install dependencies in Terminal:
     cd MacOs
     pip3 install -r requirements.txt

4. macOS Permissions (Apple Events / Automation):
   When first running, macOS may prompt:
   "Terminal wants access to control Mail". Click "OK".
   To check permissions:
   System Settings > Privacy & Security > Automation > Ensure Terminal has "Mail" enabled.

================================================================================
4. HOW TO RUN
================================================================================

METHOD A: ONE-CLICK LAUNCHER
   - Double-click "start_macos_suite.command" in this folder or in the root folder.
   - Choose:
       1) Launch MailSweep Cleaner (Port 7890)
       2) Launch UnsubBot Unsubscriber (Port 7891)
       3) Launch Both Applications

METHOD B: LAUNCH INDIVIDUAL APPS
   - MailSweep: double-click MailSweep/run_cleaner.command
   - UnsubBot:  double-click UnsubBot/run_unsubscriber.command
